# ESSAI Academic Projects & Practical Work (TPs)

This repository serves as a consolidated portfolio of coursework, practical lab sessions (TPs), and academic projects completed during my engineering program at **ESSAI**. It organizes various core implementations across programming, statistical modeling, and data analysis into three main modules:

* **`JAVA/`**: Object-oriented programming projects, core Java implementations, and software development coursework.
* **`REGRESSION/`**: Practical applications of statistical modeling, including multiple linear regression, economic income-consumption analysis, and agricultural yield evaluations.
* **`TIME_SERIES/`**: Analysis of dynamic data models covering autoregressive processes (AR), ARMA frameworks, ACF/PACF evaluations, and trend removal/differencing techniques.
